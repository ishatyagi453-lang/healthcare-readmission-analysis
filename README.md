# healthcare-readmission-analysis

## Project Overview

This project is a healthcare data science project focused on analyzing and predicting
30-day hospital readmission among patients with diabetes.

The project covers the complete data science planning process, including data
collection, data cleaning, exploratory data analysis, feature engineering,
machine learning, evaluation, ethical considerations, and risk assessment.

## Week 1 – Project Planning and Strategy

The Week 1 task focuses on developing a detailed project plan for the healthcare
data analysis project.

### Objectives

- Understand the healthcare dataset and its structure.
- Identify factors associated with hospital readmission.
- Plan the data cleaning and exploratory analysis process.
- Define appropriate healthcare analytics metrics.
- Plan a machine-learning approach for readmission prediction.
- Identify ethical, privacy, fairness, and data-quality risks.
- Develop a project timeline and resource plan.

## Dataset

The primary dataset planned for this project is:

**Diabetes 130-US Hospitals for Years 1999–2008**

Source:
UCI Machine Learning Repository

Dataset link:
https://archive.ics.uci.edu/dataset/296/diabetes%2B130-us%2Bhospitals%2Bfor%2Byears%2B1999-2008

The dataset contains hospital encounters involving patients with diabetes and
includes information such as demographics, admission details, diagnoses,
laboratory tests, medications, and readmission status.
